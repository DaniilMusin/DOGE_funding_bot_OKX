# DOGE Funding Rate Bot - OKX

Автоматический бот для мониторинга funding rates (ставок финансирования) пары DOGE-USDT на бирже OKX.

## Описание

Бот мониторит текущую ставку финансирования для DOGE perpetual futures на бирже OKX и предупреждает когда ставка превышает заданный порог. Это полезно для трейдеров, которые хотят отслеживать стоимость удержания позиций.

## Возможности

- ✅ Мониторинг текущей funding rate для DOGE-USDT-SWAP
- ✅ Отображение рыночной информации (цена, объем)
- ✅ История funding rates
- ✅ Уведомления при превышении порога
- ✅ Настраиваемый интервал проверки
- ✅ Логирование в файл и консоль
- ✅ Работает с публичными endpoints (API ключи опциональны)

## Требования

- Python 3.8+
- pip

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd DOGE_funding_bot_OKX
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте конфигурацию:
```bash
cp .env.example .env
```

Отредактируйте `.env` файл при необходимости:
```env
# OKX API credentials (опционально для публичных данных)
OKX_API_KEY=your_api_key_here
OKX_SECRET_KEY=your_secret_key_here
OKX_PASSPHRASE=your_passphrase_here

# Настройки бота
SYMBOL=DOGE-USDT-SWAP
CHECK_INTERVAL=300          # Интервал проверки в секундах (300 = 5 минут)
FUNDING_THRESHOLD=0.01      # Порог для уведомлений (0.01 = 1%)

# Демо режим (используйте когда API заблокирован)
DEMO_MODE=false             # true для демо-данных, false для реального API

# Логирование
LOG_LEVEL=INFO
```

## Запуск

Запустите бота:
```bash
python main.py
```

Бот начнет мониторить funding rate и выводить информацию в консоль и лог-файл `bot.log`.

### Демо режим

Если API OKX недоступен (блокировка региона, сетевые ограничения), включите демо-режим:

```bash
# В файле .env установите:
DEMO_MODE=true
```

В демо-режиме бот будет генерировать случайные, но реалистичные данные для демонстрации функционала. Это полезно для:
- Тестирования бота
- Разработки и отладки
- Демонстрации функционала
- Работы в регионах с ограниченным доступом к API OKX

## Что такое Funding Rate?

Funding rate (ставка финансирования) - это периодический платеж между трейдерами на рынке perpetual futures:

- **Положительная ставка** (funding rate > 0): Держатели длинных позиций (longs) платят держателям коротких позиций (shorts). Это означает, что рынок в бычьем настроении.

- **Отрицательная ставка** (funding rate < 0): Держатели коротких позиций платят держателям длинных позиций. Это означает, что рынок в медвежьем настроении.

Платежи обычно происходят каждые 8 часов на большинстве бирж.

## API Ключи

Для получения публичных данных (funding rates, цены) API ключи **не требуются**.

Если вы хотите использовать приватные endpoints (торговля, баланс), получите API ключи на OKX:
1. Войдите в аккаунт OKX
2. Перейдите в настройки API
3. Создайте новый API ключ
4. Добавьте ключи в `.env` файл

## Безопасность

- ⚠️ Никогда не коммитьте `.env` файл с реальными API ключами
- ⚠️ Храните API ключи в безопасности
- ⚠️ Используйте только чтение (read-only) права для API ключей, если не планируете торговать
